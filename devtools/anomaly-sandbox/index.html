Samples arrive every 5 seconds; detection polls every 10. Allow roughly 15–40 seconds for a new incident. Recovery takes about 30–60 seconds. The module includes a five-second incomplete tail delay.

2. Follow the incident

  1. Sign in, then open Anomaly detection. The source is Local Mimir, tenant local-sandbox, prefix /prometheus. The enabled metric is Checkout value outside 0–20.
  2. Trigger a spike. Open the incident assigned to Local Dev User in Local sandbox, then acknowledge it.
  3. Restore healthy values. The alert resolves and an Anomaly recovered timeline entry appears. The incident stays acknowledged until you resolve it yourself. Resolve it before another scenario if you want a fresh incident; otherwise Aegis can group the next alert into it.
  4. Use previews/charts and add feedback in the module. Discovery creates one metric per label set with delivery off. AR, S-H-ESD and intersection examples start disabled; preview them after at least 2–3 minutes of samples.

Stop and resume

From the Aegis checkout in WSL or Linux, run make anomaly-sandbox-down to stop the sandbox and retain its data. Run make anomaly-sandbox to resume. Use make anomaly-sandbox-status or make anomaly-sandbox-logs to inspect it. See devtools/anomaly-sandbox/README.md for PowerShell commands, source queries and failure scenarios.
