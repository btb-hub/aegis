# How-to guides

Open these **HTML** pages in a browser. They are the **user manual** for the on-call workflow
(same visual language as [`overview.html`](../overview.html)).

English and Russian: switch **EN / RU** in the page header, or open `ru/` directly.

```bash
open docs/how-to/index.html      # English
open docs/how-to/ru/index.html   # Russian
```

| Guide | English | Russian | Use when |
|-------|---------|---------|----------|
| Hub | [index.html](./index.html) | [ru/index.html](./ru/index.html) | Map of the workflow |
| Set up the workflow | [setup.html](./setup.html) | [ru/setup.html](./ru/setup.html) | Admin, first project |
| Routing rules | [routing.html](./routing.html) | [ru/routing.html](./ru/routing.html) | Label → team, with filled-in examples |
| Escalation paths | [paths.html](./paths.html) | [ru/paths.html](./ru/paths.html) | L2→L3, NOC chain, shared L3 |
| Work an incident | [incidents.html](./incidents.html) | [ru/incidents.html](./ru/incidents.html) | You are on call |
| Connect Jira / Slack / eXpress | [connect.html](./connect.html) | [ru/connect.html](./ru/connect.html) | Tickets and paging |
| When it does not route | [troubleshooting.html](./troubleshooting.html) | [ru/troubleshooting.html](./ru/troubleshooting.html) | Alerts without incidents |
