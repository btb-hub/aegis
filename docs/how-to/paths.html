Admin · escalation paths

How L2 is allowed to hand work to L3.

A support tier on a team is only a badge until you add a path. The path is the allow-list: “from this team, the incident screen may offer that team.” You add it on the source team (the one that will click the button), under Escalation paths → Outgoing paths → Add path.

02

Allowed from → to

The To team select only lists teams whose tier is legal for the source. Both teams need a support tier set (Save tier on team settings).

That empty-state on Add path means there is no L3 (or L2/L1) team yet, the only candidate already has a path, or you need Allow team from another workspace because the target lives elsewhere. Create the target team and set its tier first.

03

Where to click

Open the team that will click Hand off

Sidebar Teams → Platform L2 (not L3). Scroll to Escalation paths. You will see Outgoing paths (empty at first) and Incoming paths (paths other teams already point at this team).

Add path

Click Add path. Optionally check Allow team from another workspace. Choose To team. Confirm. Toast: Escalation path added.

Confirm on both sides

L2 Outgoing paths shows To team = Platform L3. Open Platform L3 — Incoming paths shows From team = Platform L2.

NOC incidents show Escalate to L1 and Escalate to L2. L1 sees Escalate to L2. L2 sees Hand off to L3. You cannot add NOC → L3; that pair is not allowed. Route monitoring to NOC with a routing rule, then let people walk the chain.
