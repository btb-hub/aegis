Подключите Jira, Slack и eXpress в интерфейсе.

Тикет и пэйдж не обязательны, чтобы инцидент существовал, но так работу видит остальная компания. Настраивайте в Настройки → Интеграции и на каждой рабочей области.

01

Глобальные коннекторы

Сайдбар → Настройки → Интеграции. Это значения по умолчанию, которые области могут наследовать.

Jira

Добавить интеграцию или Настроить. Выберите Server / Data Center или Cloud отдельно от типа авторизации. Для Server/DC обычно нужен Bearer с PAT, для Cloud Basic с email и API-токеном. Укажите базовый URL (включая путь Jira) и ключ проекта. Сохранить, затем Проверить подключение. Проверка подтверждает только авторизацию; отправьте алерт с подходящим маршрутом, чтобы проверить создание, назначение и видимость тикета на доске.

Slack

Нажмите Настроить Slack в карточке бота. Установите приложение Slack с chat:write, сохраните Bot User OAuth Token и Signing Secret. Включите Interactivity и укажите показанный Request URL: https://<public-aegis-origin>/api/v1/callbacks/slack/interactive. Slack должен иметь HTTPS-доступ к нему. Проверить подключение проверяет токен; доставку и кнопку Принять проверяйте реальным сообщением. ЛС идут привязанному пользователю, объявления в канал команды, куда добавлен бот. Сохранённые секреты действуют без перезапуска API. Настройка бота отделена от входа через Slack.

eXpress

Сохраните ID бота, хост CTS и секрет, затем Проверить подключение. Задайте глобальный ID группового чата дежурств eXpress для объявлений и обновлений инцидентов. Добавьте бота в группу. Дежурные подключают eXpress в Аккаунт → Мессенджеры для пейджинга и открывают личный чат с ботом для персональных пэйджей.

Проверка

Нужные коннекторы включены, а проверка подключения проходит. Если строка просит добавить учётные данные для завершения настройки, откройте Настроить.

02

Слоты рабочей области

У каждой области слоты Jira, Slack и eXpress. Откройте область → Интеграции.

РежимКогда
НаследоватьГлобальный коннектор. У Jira можно свой ключ проекта (Platform → OPS, Data → DATA), у Slack свой канал. Возврат к этому режиму удаляет секреты слота рабочей области.
СобственныеПолные свои учётные данные, без смешивания с глобальными.

В слоте Slack нажмите Настроить глобальный Slack, чтобы изменить общий бот. Для отдельного бота выберите Собственные и сохраните токен и Signing Secret. Команды используют бот своей рабочей области. Сохранять секреты и проверять подключения может только администратор. Участники и наблюдатели могут смотреть список и попросить администратора завершить настройку.

Состояния слота: Готово, Использует глобальную, Требует настройки, Нет глобальной, Выключена. Выключенный слот пропускает провайдера при обработке и не блокирует инцидент.

03

Кого пэйджить в Аккаунте

Вход и пэйджинг разделены. Вход через Google сам по себе не даёт Aegis адресата ЛС в Slack.

  1. Каждый дежурный открывает Аккаунт → Мессенджеры для пейджинга и нажимает Подключить для Slack или eXpress. Завершите авторизацию в браузере и вернитесь в Аккаунт. Подключение уведомлений не добавляет провайдер входа.
  2. Для eXpress без корпоративного SSO выберите Подключить eXpress через бота → Сгенерировать код привязки в том же разделе Аккаунта. Скопируйте команду /link <code> и отправьте её в личный чат с ботом Aegis, затем нажмите Проверить подключение в Аккаунте. Код действует 15 минут, используется один раз и должен оставаться приватным. Генерация и копирование кода сами по себе не подключают аккаунт. Прежняя привязка сохраняется, пока бот не примет команду. Администратору всё равно нужно настроить бота и его callback.
  3. Заменить сохраняет прежнее подключение до успешной авторизации. Отключить требует подтверждения и прекращает пэйджи через этот мессенджер, сохраняя способы входа.
  4. Если подключение через браузер недоступно, администратор должен настроить OIDC провайдера и включить глобальный бот. Slack должен соответствовать рабочему пространству глобального бота; eXpress SSO должен передать подтверждённый email ровно одного активного пользователя мессенджера.
  5. Язык English / Русский тоже здесь; персональные пэйджи и приватные результаты действий в чате идут на языке получателя.

Требования для администратора и совместимость старого API: Подключение мессенджеров.

Общие каналы и проверка доставки

На странице команды задайте ID канала Slack и, при необходимости, ID тега команды Slack (ID группы пользователей). Бот рабочей области должен иметь доступ к каналу. Общие сообщения eXpress идут в глобальный чат дежурств, даже если персональные пэйджи используют отдельные настройки области.

Создайте тестовый инцидент через маршрут и проверьте тикет Jira, личный пэйдж и общий пост. Нажмите Принять в чате. В настроенной группе дежурных eXpress успех подтверждает общий пост о принятии; в других поддерживаемых чатах приходит приватный результат. Затем закройте инцидент в Aegis и проверьте обновление канала. Создание, принятие, закрытие и эскалация дают отдельные посты; передача и возврат в эту функцию не входят. Worker должен работать.

04

Нет коннектора, инцидент всё равно будет

Если Jira или чат не готовы, алерт и инцидент всё равно создаются. В ленте событие integration_skipped с причиной: слот выключен, нет глобального коннектора или собственная конфигурация неполна. Исправьте слот. Не пересылайте вебхук, если вам не нужен дубликат алерта.

Контракты коннекторов: docs/integrations. Назад к настройке процесса.
