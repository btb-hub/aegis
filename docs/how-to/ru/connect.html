Админ · коннекторы

Подключите Jira, Slack и eXpress в интерфейсе.

Тикет и пэйдж не обязательны, чтобы инцидент существовал, но так работу видит остальная компания. Настраивайте на Интеграции и на каждой рабочей области. Мастер не нужен, чтобы сменить один секрет.

01

Глобальные коннекторы

Сайдбар → Интеграции. Это значения по умолчанию, которые области могут наследовать.

Jira

Добавить интеграцию или Настроить. Базовый URL, email, API-токен, ключ проекта. Сохранить, затем Проверить подключение.

Slack

Токен бота и signing secret. ЛС идут на Slack user ID пользователя. Объявления — на ID канала команды.

eXpress

ID бота, хост, секрет. Кто вошёл через Google или Slack, всё равно привязывает eXpress в Аккаунт.

02

Слоты рабочей области

У каждой области слоты Jira, Slack и eXpress. Откройте область → Интеграции.

РежимКогда
НаследоватьГлобальный коннектор. У Jira можно свой ключ проекта (Platform → OPS, Data → DATA).
СобственныеПолные свои учётные данные, без смешивания с глобальными.
03

Кого пэйджить — в Аккаунте

  1. Каждый дежурный открывает Аккаунт.
  2. Slack: подключить Slack, чтобы появился Slack user ID.
  3. eXpress: Сгенерировать код привязки и /link в eXpress.
  4. Язык English / Русский тоже здесь — тексты пэйджей идут на языке получателя.
04

Нет коннектора — инцидент всё равно будет

Если Jira или чат не готовы, алерт и инцидент всё равно создаются. В ленте событие integration_skipped. Почините слот, не пересылайте вебхук без нужды — получите дубль алерта.

Контракты коннекторов: docs/integrations. Назад к настройке процесса.
