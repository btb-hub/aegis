# Как L2 разрешают передать работу в L3.

Уровень поддержки на команде — только бейдж, пока нет **пути**. Путь — это
список разрешений: «с этой команды экран инцидента может предложить ту команду». Путь
добавляют на **исходной** команде (той, кто нажмёт кнопку): **Пути эскалации** →
**Исходящие пути** → **Добавить путь**.

[Чем путь отличается от правила](#why) | [Какие уровни куда можно](#allowed) | [Куда нажимать](#where) | [Пример: L2 → L3](#ex1) | [Пример: цепочка NOC](#ex2) | [Пример: общий L3](#ex3) | [Пустой список / нет кнопки](#empty)

<a id="why"></a>

## 01 · Правило маршрутизации и путь

|  | Правило маршрутизации | Путь эскалации |
| --- | --- | --- |
| Вопрос | Какая команда владеет **новым** алертом? | Куда эта команда может **передать** открытый инцидент? |
| Где настраивают | **Рабочие области** → проект → **Правила маршрутизации** | **Команды** → исходная команда → **Пути эскалации** |
| Типичная цель | L2 или NOC | Следующий уровень (L3, или L2 с NOC/L1) |
| Если нет | Алерт не становится инцидентом | Нет кнопки **Передать в L3** / эскалации, или пустой список целей |

**Вернуть в L2** — не путь.
L3 нажимает **Вернуть в L2**, инцидент уходит предыдущему владельцу.

<a id="allowed"></a>

## 02 · Откуда → куда можно

В **В команду** попадают только команды с допустимым уровнем. У обеих команд
уровень должен быть сохранён (**Сохранить уровень** в настройках команды).

| Уровень исходной команды | Можно добавить путь в | Кнопка на инциденте |
| --- | --- | --- |
| NOC | L1 или L2 | Эскалировать в L1 / Эскалировать в L2 |
| L1 | L2 | Эскалировать в L2 |
| L2 | L3 | Передать в L3 |
| L3 | Исходящих путей нет | Вернуть в L2 (это не путь) |

> **Нет подходящих команд для этого уровня**
>
> Так пишет пустое состояние **Добавить путь**: ещё нет команды L3 (или L2/L1), единственный
> кандидат уже в списке, либо цель в другой области — включите
> **Разрешить команду из другой области**. Сначала создайте целевую команду и задайте ей уровень.

<a id="where"></a>

## 03 · Куда нажимать

1. **Откройте команду, которая нажмёт «Передать»**
   Сайдбар **Команды** → **Platform L2** (не L3). Блок **Пути эскалации**:
   **Исходящие пути** (пока пусто) и **Входящие пути** (кто уже указывает на эту команду).

2. **Добавить путь**
   **Добавить путь**. При необходимости **Разрешить команду из другой области**.
   Выберите **В команду**. Тост: **Путь эскалации добавлен**.

3. **Проверьте обе стороны**
   У L2 в исходящих: В команду = Platform L3. У Platform L3 во входящих: Из команды = Platform L2.

<a id="ex1"></a>

## 04 · Пример 1 — Platform L2 → Platform L3

Минимум для большинства проектов. Команды с уровнями L2 и L3 уже есть в области Platform.

#### Добавить путь · команда **Platform L2**

| Поле | Значение |
|-------|-------|
| Разрешить команду из другой области | Выкл. |
| В команду | Platform L3 |

На инциденте Platform L2 инженер видит **Передать в L3** и выбирает Platform L3.
Aegis пэйджит того, кто в **Сейчас на смене** у Platform L3. Если у L3 нет графика, передача
упадёт с подсказкой открыть **Смены**.

<a id="ex2"></a>

## 05 · Пример 2 — NOC → L1 → L2 → L3

Четыре команды в Platform: Platform NOC, Platform L1, Platform L2, Platform L3.
Нужны три (или четыре) пути.

#### Путь 1 · на **Platform NOC**

| Поле | Значение |
|-------|-------|
| В команду | Platform L1 |

#### Путь 2 · на **Platform NOC** (обход L1)

| Поле | Значение |
|-------|-------|
| В команду | Platform L2 |

#### Путь 3 · на **Platform L1**

| Поле | Значение |
|-------|-------|
| В команду | Platform L2 |

#### Путь 4 · на **Platform L2**

| Поле | Значение |
|-------|-------|
| В команду | Platform L3 |

У NOC будут «Эскалировать в L1» и «Эскалировать в L2». У L1 — «Эскалировать в L2».
У L2 — «Передать в L3». NOC → L3 добавить нельзя. Алерты на NOC ведите
[правилом маршрутизации](routing.md#ex3).

<a id="ex3"></a>

## 06 · Пример 3 — Data L2 пользуется Platform L3

У Data нет своего L3. Специалисты живут в Platform L3.

#### Добавить путь · команда **Data L2**

| Поле | Значение |
|-------|-------|
| Разрешить команду из другой области | Вкл. |
| В команду | Platform L3 (Platform) |

Без галочки Platform L3 в списке не появится. Позже можно добавить и Data L3 —
в пикере будут обе цели. Во входящих у Platform L3 появится Data L2.

<a id="empty"></a>

## 07 · Что видит дежурный, если путь кривой

| На инциденте | Что сделать в Командах |
| --- | --- |
| Нет кнопки Передать / Эскалировать | У команды-владельца нет исходящего пути. Откройте её, **Добавить путь**. |
| Подсказка: цели эскалации не настроены | То же — нет пути или у цели сняли уровень. |
| Ошибка: в целевой команде никто не дежурит | Путь верный. Откройте **Смены** у *целевой* команды и создайте график. |
| В пикере чужой L3 (Platform L3 на инциденте Data) | Добавлен межобластный путь. Удалите его, если так не задумано. |

> **Проверка**
>
> Исходящие исходной команды содержат цель. Входящие цели содержат источник. На тестовом
> инциденте L2 кнопка **Передать в L3** показывает эту L3.
