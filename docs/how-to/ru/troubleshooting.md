# Когда процесс собран не до конца.

Сверьте с тем, что видно в продукте. Чаще всего нет правила маршрутизации,
пустая ротация или человек ни разу не входил. Docker и `.env` — в
[07-setup-deployment.md](../../07-setup-deployment.md).

## 01 · Симптом → куда нажать

| Вы видите | Что это | Куда |
| --- | --- | --- |
| Строки в **Алертах**, пусто в **Инцидентах** | Вебхук дошёл. Ни одно правило не совпало с метками. | **Рабочие области** → проект → **Добавить правило**. Сверьте ключ и значение с алертом. Примеры: [правила](routing.md). |
| Инцидент есть, **Сейчас на смене** пусто | Нет графика на это время. | **Смены** этой команды → **Создать график** или **Добавить подмену**. |
| Нет кнопки **Передать в L3** | У команды-владельца нет исходящего пути. | **Команды** → эта команда → **Пути эскалации** → **Добавить путь**. Примеры: [пути](paths.md). |
| Пикер передачи пустой | Путь есть, но цель исчезла, без уровня, или в другой области без галочки. | Поправьте путь. **Разрешить команду из другой области** — только для общего L3. |
| Поиск участников никого не находит | Эти люди ещё не входили. | Пусть зайдут на страницу входа один раз, затем снова **Добавить участника**. |
| Нельзя создать команды | Роль Участник или Наблюдатель. | **Аккаунт** показывает роль. Админ повышает в **Пользователи**. |
| Инцидент без тикета Jira / без пэйджа | Слот не готов или нет идентификатора в Аккаунте. | **Проверить подключение**. Пользователь открывает **Аккаунт** и привязывает Slack/eXpress. |
| **Подключить** в Аккаунте недоступно | Не настроен OIDC провайдера или глобальный бот. | Администратор завершает [настройку подключения](../../features/paging-connections.md). Настроек отдельной области недостаточно для авторизации из Аккаунта. |
| Личный пэйдж есть, общего поста нет | Не задан общий чат или у бота нет доступа. | Проверьте канал Slack команды и бот области; для eXpress глобальный чат дежурств и глобальный бот. |
| После нажатия в чате нет приватного результата | Приём запроса не означает подтверждение; обработка worker или доставка результата могли завершиться ошибкой. | Проверьте статус инцидента в вебе. Оператор проверяет логи worker и `chat_ack_requests`; см. [диагностику доставки](../../features/incident-chat-notifications.md). |

## 02 · Чеклист админа перед боем

- У каждого проекта есть **рабочая область**.
- L2 и L3 с правильным **уровнем поддержки**.
- Дежурные **входили** и добавлены в команду.
- У L2 есть **путь эскалации** на L3.
- **Сейчас на смене** называет человека.
- У области есть **правило маршрутизации** под реальные метки.
- **Проверить подключение** прошло для нужных коннекторов.
- Дежурные подключили Slack/eXpress в **Аккаунт → Мессенджеры для пейджинга**.
- Тестовый инцидент через маршрут даёт тикет, личный пэйдж, общий пост и приватный результат подтверждения в чате для настроенных каналов.
