Админ · правила маршрутизации

Как метка на алерте выбирает команду.

Правило маршрутизации — это одно совпадение: этот ключ метки равен этому значению → инцидент уходит в эту команду. Правило создают на рабочей области проекта, не на команде. Если ни одно правило не совпало, алерт остаётся в Алертах и не становится инцидентом.

01

Где создать правило

Откройте рабочую область, не Команды

В сайдбаре Рабочие области → Platform (или ваш проект). Блок Правила маршрутизации → Добавить правило. Сохранение — Сохранить правило.

Одно правило = одно совпадение

В форме один Ключ метки и одно Значение метки. Два условия на одном правиле (И) в интерфейсе нельзя. Лишние метки на алерте не мешают — правило не обязано перечислять их все.

02

Что значит каждое поле

ПолеЧто указать
Разрешить команду из другой области Выключено, если целевая команда в этой же области. Включайте только для общей команды (например DevOps в другой области). Тогда в Целевая команда появятся чужие команды.
Целевая команда Кто станет владельцем инцидента. Обычно L2 или NOC. Не L3 — L3 получает работу по пути эскалации, не из маршрутизации.
Ключ метки Точное имя метки из мониторинга. Часто team, project, service. Регистр важен.
Значение метки Точное значение. platform не совпадёт с Platform или platform-prod.
Приоритет Целое число. По умолчанию 100. Большее число проверяется первым, если два правила подошли к одному алерту. При равном приоритете не полагайтесь на порядок — задайте разные числа.
Сопоставление глобальное

Aegis смотрит правила всех рабочих областей вместе. Правило с высоким приоритетом в Data может перехватить алерт Platform, если метки те же. Делайте матчер узким (team=… или project=…), а не голый severity=critical, если не хотите все critical в одну команду.

07

Если не знаете имена меток

  1. Пришлите один реальный алерт (или Мастер настройки → Отправить тестовый алерт).
  2. Откройте Алерты → строку → метки.
  3. Скопируйте одну пару ключ/значение в Добавить правило и сохраните.
  4. Повторите алерт. Должен появиться инцидент.
Проверка

В таблице правил рабочей области есть хотя бы одна строка. Новый подходящий алерт виден в Инцидентах на целевой команде. Дальше команде нужны пути эскалации и дежурный.
