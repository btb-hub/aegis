Админ · пути эскалации

Как L2 разрешают передать работу в L3.

Уровень поддержки на команде — только бейдж, пока нет пути. Путь — это список разрешений: «с этой команды экран инцидента может предложить ту команду». Путь добавляют на исходной команде (той, кто нажмёт кнопку): Пути эскалации → Исходящие пути → Добавить путь.

Чем путь отличается от правила Какие уровни куда можно Куда нажимать Пример: L2 → L3 Пример: цепочка NOC Пример: общий L3 Пустой список / нет кнопки

02

Откуда → куда можно

В В команду попадают только команды с допустимым уровнем. У обеих команд уровень должен быть сохранён (Сохранить уровень в настройках команды).

Нет подходящих команд для этого уровня

Так пишет пустое состояние Добавить путь: ещё нет команды L3 (или L2/L1), единственный кандидат уже в списке, либо цель в другой области — включите Разрешить команду из другой области. Сначала создайте целевую команду и задайте ей уровень.

03

Куда нажимать

Откройте команду, которая нажмёт «Передать»

Сайдбар Команды → Platform L2 (не L3). Блок Пути эскалации: Исходящие пути (пока пусто) и Входящие пути (кто уже указывает на эту команду).

Добавить путь

Добавить путь. При необходимости Разрешить команду из другой области. Выберите В команду. Тост: Путь эскалации добавлен.

Проверьте обе стороны

У L2 в исходящих: В команду = Platform L3. У Platform L3 во входящих: Из команды = Platform L2.

04

Пример 1 — Platform L2 → Platform L3

Минимум для большинства проектов. Команды с уровнями L2 и L3 уже есть в области Platform.

Добавить путь · команда Platform L2
Разрешить команду из другой области
Выкл.
В команду
Platform L3

На инциденте Platform L2 инженер видит Передать в L3 и выбирает Platform L3. Aegis пэйджит того, кто в Сейчас на смене у Platform L3. Если у L3 нет графика, передача упадёт с подсказкой открыть Смены.

05

Пример 2 — NOC → L1 → L2 → L3

Четыре команды в Platform: Platform NOC, Platform L1, Platform L2, Platform L3. Нужны три (или четыре) пути.

Путь 1 · на Platform NOC
В команду
Platform L1
Путь 2 · на Platform NOC (обход L1)
В команду
Platform L2
Путь 3 · на Platform L1
В команду
Platform L2
Путь 4 · на Platform L2
В команду
Platform L3

У NOC будут «Эскалировать в L1» и «Эскалировать в L2». У L1 — «Эскалировать в L2». У L2 — «Передать в L3». NOC → L3 добавить нельзя. Алерты на NOC ведите правилом маршрутизации.

06

Пример 3 — Data L2 пользуется Platform L3

У Data нет своего L3. Специалисты живут в Platform L3.

Добавить путь · команда Data L2
Разрешить команду из другой области
Вкл.
В команду
Platform L3 (Platform)

Без галочки Platform L3 в списке не появится. Позже можно добавить и Data L3 — в пикере будут обе цели. Во входящих у Platform L3 появится Data L2.

07

Что видит дежурный, если путь кривой

На инцидентеЧто сделать в Командах
Нет кнопки Передать / Эскалировать У команды-владельца нет исходящего пути. Откройте её, Добавить путь.
Подсказка: цели эскалации не настроены То же — нет пути или у цели сняли уровень.
Ошибка: в целевой команде никто не дежурит Путь верный. Откройте Смены у целевой команды и создайте график.
В пикере чужой L3 (Platform L3 на инциденте Data) Добавлен межобластный путь. Удалите его, если так не задумано.
Проверка

Исходящие исходной команды содержат цель. Входящие цели содержат источник. На тестовом инциденте L2 кнопка Передать в L3 показывает эту L3.

Кто забирает новый алерт: правила маршрутизации. Кнопки дежурного: работа с инцидентом.
