Когда процесс собран не до конца.

Сверьте с тем, что видно в продукте. Чаще всего нет правила маршрутизации, пустая ротация или человек ни разу не входил. Docker и .env — в 07-setup-deployment.md.

01

Симптом → куда нажать

Вы видитеЧто этоКуда
Строки в Алертах, пусто в Инцидентах Вебхук дошёл. Ни одно правило не совпало с метками. Рабочие области → проект → Добавить правило. Сверьте ключ и значение с алертом. Примеры: правила.
Инцидент есть, Сейчас на смене пусто Нет графика на это время. Смены этой команды → Создать график или Добавить подмену.
Нет кнопки Передать в L3 У команды-владельца нет исходящего пути. Команды → эта команда → Пути эскалации → Добавить путь. Примеры: пути.
Пикер передачи пустой Путь есть, но цель исчезла, без уровня, или в другой области без галочки. Поправьте путь. Разрешить команду из другой области — только для общего L3.
Поиск участников никого не находит Эти люди ещё не входили. Пусть зайдут на страницу входа один раз, затем снова Добавить участника.
Нельзя создать команды Роль Участник или Наблюдатель. Аккаунт показывает роль. Админ повышает в Пользователи.
Инцидент без тикета Jira / без пэйджа Слот не готов или нет идентификатора в Аккаунте. Проверить подключение. Пользователь открывает Аккаунт и привязывает Slack/eXpress.
02

Чеклист админа перед боем

  1. У каждого проекта есть рабочая область.
  2. L2 и L3 с правильным уровнем поддержки.
  3. Дежурные входили и добавлены в команду.
  4. У L2 есть путь эскалации на L3.
  5. Сейчас на смене называет человека.
  6. У области есть правило маршрутизации под реальные метки.
  7. Проверить подключение прошло для нужных коннекторов.
