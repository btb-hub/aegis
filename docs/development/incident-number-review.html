Полный локальный gate прошёл

make lint type test с PostgreSQL 16 завершился успешно, включая все 352 веб-теста.

API coverage проходит с результатом 90,6%. Прежние 85,9% получались без DATABASE_URL, когда DB-тесты пропускались. Порог 90% не менялся.

Причина падения CI в PR #69 исправлена: ответ бота для удалённого инцидента использует UUID из запроса. Остальные ошибки БД возвращаются как ошибки, проверка рабочей области сохранена. Регрессионный тест сначала воспроизвёл сбой, затем прошёл.

Перед запуском

Нужна миграция 000024_incident_numbers. Она заполнит номера существующих инцидентов по времени создания и кратковременно возьмёт эксклюзивную блокировку таблицы. Конкретный номер инцидента ee1d32ca… зависит от его места в базе.

Production не менялся. Live Jira и BotX не проверялись; интеграционные тесты использовали локальные HTTP-фикстуры.
